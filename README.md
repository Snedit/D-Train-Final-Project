# D-Train-Final-Project

### To be able to run or test the application:
* set all the env variables needed by the backend such as : 
SUPABASE_URL,
SUPABASE_SERVICE_ROLE,
REDIS_URL,
JWT_SECRET, 

- install docker desktop and run a redis container by
```
docker run --name node-redis -p 6379:6379 -d redis
```
